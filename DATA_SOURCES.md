# Public sources

## NLR Dataset 205

- Landing page: https://data.nlr.gov/submissions/205
- California archive: https://data.nlr.gov/system/files/205/California-1679428758.zip
- License page: https://data.nlr.gov/node/205/license
- DOI: https://doi.org/10.7799/1916473
- Expected archive SHA256: `d471d50c91e94ca4b52f626e9677445062910bf6a208acbfaed00c01122b3e0e`

The package uses the baseline, HVAC demand response, HVAC precooling, long run marginal carbon, and grid value series from the California archive. The source contains modeled profiles. It is not a measured site record. Retain the source license and attribution when redistributing source data.

## PVWatts V8

- Documentation: https://developer.nlr.gov/docs/solar/pvwatts/v8/
- API endpoint: https://developer.nlr.gov/api/pvwatts/v8.json

The fixed request uses latitude `34.1478`, longitude `-118.1445`, one kilowatt capacity, a 20 degree tilt, 180 degree azimuth, the NSRDB data source, and hourly output.

## Converter efficiency source

- Datasheet: https://www.synqor.com/document-download?document=BQ4H480FTx64+Datasheet.pdf

The numerical configuration records a generic curve fit from this public source. It does not identify a specific installed device.
